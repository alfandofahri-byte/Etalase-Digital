CARA PASANG
1. Start Apache dan MySQL di XAMPP.
2. Taruh folder etalase-digital di C:\xampp\htdocs\
3. Buka http://localhost/phpmyadmin
4. Import database.sql.
5. Buka http://localhost/etalase-digital/
